# Full MC Production

Follow [AGENTS.md](AGENTS.md) for repository instructions. Use `./mcprod` for
production configuration, runtime preparation, SOURCE/SHARD planning, CERN
scheduling, handoff, and IHEP batches.

- Review the [command reference](docs/README.md) and
  [test procedures](docs/testing.md) before preparing or operating a run.
- Use `./tests/run_all_tests.sh` for offline verification.
- Use the frozen runtime and matching Git revision for historical runs.
  [Historical production workflows](docs/legacy-production.md)
